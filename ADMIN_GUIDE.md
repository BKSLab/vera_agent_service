# Инструкция: просмотр диалогов и обратной связи через `/admin`

Административная панель Agent Service предназначена для просмотра
сохранённых сессий, реплик и пользовательских отзывов.

## Локальный запуск

1. Убедитесь, что в `.env` заполнены:

   - `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_NAME`;
   - `POSTGRES_USER`, `POSTGRES_PASSWORD`;
   - `SECRET_KEY`;
   - `ADMIN_LOGIN`, `ADMIN_PASSWORD`;
   - `API_KEY`.

2. Запустите PostgreSQL:

   ```bash
   docker compose up -d db
   ```

3. Примените миграции:

   ```bash
   alembic upgrade head
   ```

4. Запустите сервис:

   ```bash
   hypercorn app.main:app --bind 0.0.0.0:8000 --reload
   ```

5. Откройте `http://localhost:8000/admin/login`.

При полном запуске через Docker миграции автоматически выполняются
`entrypoint.sh` до старта приложения:

```bash
docker compose up -d --build
```

## Вход

Введите значения `ADMIN_LOGIN` и `ADMIN_PASSWORD` из `.env`. Авторизация
админки отделена от `X-API-Key`, которым BFF сайта вызывает feedback API.

## Сессии

Раздел «Сессии» показывает:

- `session_id`;
- `user_id`, если пользователь был авторизован;
- дату создания;
- дату последней активности.

Нажатие на `session_id` открывает полную хронологию диалога.

## Реплики

Раздел «Реплики» показывает:

- `request_id`;
- связанную сессию;
- вопрос пользователя;
- фактически отправленный ответ Веры;
- статус обработки;
- длительность;
- дату.

В детальной карточке дополнительно доступны источники и безопасные
технические метаданные.

## Оценки ответов

Раздел «Оценки ответов» содержит оценки `up/down`, связанные с конкретными
`request_id`.

Из оценки можно перейти к полной сессии. В админке разрешено изменять
только экспертные поля:

- статус: `new`, `in_review`, `resolved`, `dismissed`;
- внутреннюю заметку;
- теги.

Вопрос, ответ и пользовательская оценка через админку не редактируются.

## Отзывы по сессиям

Раздел «Отзывы по сессиям» показывает:

- аудиторию;
- полезность;
- доверие;
- комментарий;
- маскированный email в списке;
- статус экспертной проверки.

Как и у оценки ответа, редактируются только экспертный статус, заметка и
теги.

## Просмотр полной сессии

Страница «Просмотр сессии» отображает вопросы и ответы по порядку. Если
переход выполнен из оценки конкретного ответа, нужная реплика выделяется
и прокручивается в видимую область.

## Проверка API

Feedback API состоит из двух операций:

```text
PUT  /api/v1/feedback/message
POST /api/v1/feedback/session
```

Обе операции вызываются BFF сайта с заголовком `X-API-Key`. Текст вопроса
и ответа сайт не передаёт: Agent Service сохраняет их во время обработки
RabbitMQ-запроса.
